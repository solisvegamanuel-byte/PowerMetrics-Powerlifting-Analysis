# Análisis de Datos de Powerlifting

Este repositorio contiene un análisis exploratorio y procesamiento de datos sobre competencias de **Powerlifting**, enfocado en evaluar el rendimiento de los atletas, tasas de descalificación por sexo, métricas de fuerza relativa y promedios por categoría de edad.

---

## 📊 Descripción del Proyecto

El objetivo principal de este proyecto es analizar los factores que influyen en el desempeño de los atletas en competencias de powerlifting, segmentando la información para obtener insights clave sobre:
* Proporción de descalificaciones según el sexo de los competidores.
* Comportamiento y métricas de fuerza relativa en distintas categorías.
* Rendimiento promedio de levantamiento agrupado por rangos de edad.
